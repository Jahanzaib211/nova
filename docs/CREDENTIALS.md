# Nova credentials — one page, everything

Every secret Nova can use: what it is, where it lives, where to get it.

**No real values are in this file, and none ever should be.** To make a real
backup, run `scripts/secrets-export.sh` — it writes a `0600`, gitignored file on
your machine. To see what is set right now without revealing anything, run
`scripts/secrets-doctor.sh`.

```bash
./scripts/secrets-doctor.sh     # what's set / missing / dangerous
./scripts/secrets-export.sh     # real backup, 0600, gitignored, never committed
```

---

## 🚨 Back these up first

Everything else is re-issuable from a console. These are not.

| # | Secret | If you lose it |
|---|---|---|
| 1 | `NOVA_BYOK_SECRET` | **Unrecoverable.** Fernet key encrypting every user-supplied provider key at rest. Lose it and every stored user key is orphaned permanently. |
| 2 | `backend/.deer-flow/.jwt_secret` | Every user is logged out. It is a *file*, auto-generated once, and currently exists in exactly one copy. |
| 3 | `BETTER_AUTH_SECRET`, `DEER_FLOW_INTERNAL_AUTH_TOKEN`, `NOVA_OPS_TOKEN` | Regenerable, but every service must restart together. |
| 4 | `STRIPE_WEBHOOK_SECRET` | Recoverable, but you must re-register the webhook endpoint. |

Generate a BYOK key:

```bash
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

## Where secrets live

| Deployment | Mechanism |
|---|---|
| **Docker Compose (production)** | root `.env`, via `env_file:` in `docker/docker-compose*.yaml` |
| **Kubernetes** | one Secret `nova-secrets`, created by `k8s/scripts/bootstrap-secrets.sh` (48 keys: 5 generated + 43 read from `.env`) |
| **Cloudflare tunnel** | `/etc/cloudflared/env`, mode `0600`, read by systemd `EnvironmentFile=` |
| **Monitoring** | `docker/monitoring/monitoring.env`, mode `0600` |
| **Frontend** | `frontend/.env` — **only** non-secret `NEXT_PUBLIC_*` values |

> `NEXT_PUBLIC_*` is compiled into the browser bundle. **Never put a secret there.**

Gitignored and holding real values: `.env`, `config.yaml`, `extensions_config.json`,
`runtime_models.yaml`, `frontend/.env`, `backend/.deer-flow/.jwt_secret`.
Verified: no secret file has ever been committed, not even historically.

## 1. Auth & session

| Variable | What | Required? | Get it from |
|---|---|---|---|
| `BETTER_AUTH_SECRET` | Signs login sessions | **Yes** | auto-generated by `scripts/deploy.sh` |
| `AUTH_JWT_SECRET` | Signs JWTs | Auto | auto-generated → `.deer-flow/.jwt_secret`. **Set explicitly if you run >1 replica** — the auto-generate path has a check-then-act race |

| `NOVA_BYOK_SECRET` | Encrypts user API keys at rest | Optional | `Fernet.generate_key()` — see above |
| `NOVA_BYOK_ENABLED` | Must be exactly `1` **and** the key valid | Optional | — |
| `SEARXNG_SECRET_KEY` | SearXNG instance secret | Yes for search stack | `openssl rand -hex 32` |
| `DEER_FLOW_AUTH_DISABLED` | **Must be `0` in production** | — | — |
| `DEER_FLOW_ENV` | `production` blocks auth-disabled mode | — | — |
| `DEER_FLOW_TRUSTED_ORIGINS` | Allowed origins (auth + CSRF) | Yes | set in root **and** `frontend/.env` |
| `GATEWAY_CORS_ORIGINS` | CORS allowlist; also feeds the CSRF origin check | Optional | — |
| `AUTH_TRUSTED_PROXIES` | Trusted proxy IPs for client-IP extraction | Optional | — |

## Rotation

1. Change the value in the **source of truth** for that deployment (table at top).
2. Docker: `docker compose ... up -d --force-recreate <service>`.
   k8s: re-run `bootstrap-secrets.sh`, then `kubectl rollout restart deployment/gateway -n nova-staging`.
   Tunnel: `sudo systemctl restart cloudflared-nova`.
3. `./scripts/secrets-doctor.sh` to confirm.

Rotating `BETTER_AUTH_SECRET` or `AUTH_JWT_SECRET` logs everyone out. Rotating
`DEER_FLOW_INTERNAL_AUTH_TOKEN` requires gateway **and** channels to restart
together, or channel messages start failing auth.

## Housekeeping

- `config.yaml.bak` in the repo root predates `$VAR` interpolation and may hold
  literal keys. Audit and delete it.
- `bootstrap-secrets.sh` reads only from `.env`. Anything missing there is
  written to `nova-secrets` as an empty string — safe (every consumer treats
  empty as "feature disabled"), but it means k8s has whatever `.env` has.
