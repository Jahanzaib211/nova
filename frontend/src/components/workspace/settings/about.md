# [About Nova](https://github.com/Jahanzaib211/nova)

> **Nova — The Agent's Computer**

Nova is a full-stack **computer agent** that researches, codes, and creates. It orchestrates **sub-agents**, **memory**, and **per-thread sandboxes** to do almost anything — powered by **extensible skills** and a live, streaming view of the agent's own computer.

Nova is built on top of the open-source [DeerFlow](https://github.com/bytedance/deer-flow) super agent harness.

---

## 🚀 Core Features

* **Agent's Computer**: Watch Nova work in real time — live terminal, editor, browser preview, and task progress.
* **Skills & Tools**: With built-in and extensible skills and tools, Nova can do almost anything.
* **Sub-Agents**: Sub-agents help the main agent with tasks that are too complex for a single agent.
* **Per-Thread Sandboxes**: Each conversation gets its own isolated container for safe code execution and file manipulation.
* **Context Engineering**: Isolated sub-agent context, summarization to keep the context window sharp.
* **Long-Term Memory**: Keeps recording the user's profile, top of mind, and conversation history.
