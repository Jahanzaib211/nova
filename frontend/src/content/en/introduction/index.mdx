# Introduction

Nova is an AI developer that runs on your hardware. It plans work, runs commands in isolated sandboxes, verifies the result in a real browser, and delivers a signed build with an audit trail.

Start with the concepts that explain the design, then move on to the Harness or the App depending on what you are building.
