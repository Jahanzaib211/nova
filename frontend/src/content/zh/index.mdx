# Nova 文档

Nova 是一个开源的 Agent 运行时和应用平台，构建于 [DeerFlow](https://github.com/bytedance/deer-flow) harness 之上。它为你提供了一个生产就绪的 Harness，用于将 Agent 与记忆、工具、技能、沙箱和子 Agent 组合在一起 — 同时提供了完整的应用层，用于为最终用户部署和操作这些 Agent。

本文档涵盖 Nova App（如何使用）和 Nova Harness（如何扩展和嵌入）。
