# 简介

Nova 是运行在你自有硬件上的 AI 开发者。它会规划任务、在隔离沙箱中执行命令、用真实浏览器验证结果，并交付带有审计记录的签名构建。

先阅读解释设计思路的概念页面，然后根据你要构建的内容进入 Harness 或应用文档。
