The opportunity

Agent platforms are model-locked. Nova is not.

Teams want capable agents without being trapped by one vendor's API, price, or hardware. Nova is a complete agent workspace — planning, tools, a live "Agent's Computer", sandboxed browser & editor — with a config-driven model layer that runs on whatever compute you choose.

  • Swap providers with a config entry — no code changes.
  • First-class support for AMD Instinct compute, managed or bare-metal.
  • Token usage tracked end-to-end, so efficiency is measurable.

04
Architecture

Config-driven providers → AMD compute

  • UI / API → runtime model store (runtime_models.yaml), env-driven ($FIREWORKS_API_KEY resolved at load, never persisted).
  • Model factory instantiates the LangChain provider from use: — Fireworks via ChatOpenAI, AMD Instinct via the native VllmChatModel.
  • Telemetry: every run's provider is tagged AMD-backed; an AMD badge appears in the UI.
  • Signal: GET /api/models/amd-usage reports AMD usage as machine-readable JSON for pre-screening.
05
Demonstrable — and honest

AMD usage you can verify

curl /api/models/amd-usage →

{ "amd_backed": true, "count": 2, "summary": "Nova is running on AMD compute: 2 AMD-backed model(s)…" }

  • Only verifiably AMD-hosted endpoints (Fireworks) are auto-claimed.
  • Self-hosted vLLM must opt in explicitly — a bare vLLM server is never assumed to be AMD.
  • The badge never overstates where inference actually ran.
