# Blueprint: v7.4 Sprint — Nova Hooks + Receipts + Opencode Ecosystem

**One-line objective:** Ship the keystone primitives (hook surface, receipt generator, per-tool-type model routing, `nova` CLI) PLUS the operational layer (cronjobs + watchdogs + self-improving loop) PLUS the opencode skills library + native MCP ecosystem, in a 5-day hackathon sprint, with the "code is the ultimate proof" thesis visible end-to-end and the self-improving loop feeding back into the agent runtime.

**Loop pattern:** Sequential Pipeline + De-Sloppify + per-day CI gate + persistent `SHARED_TASK_NOTES.md` + magic-phrase completion signals (per the Autonomous Loops skill).

**Self-improving loop anchor:** `SelfImprovementMiddleware` writes improvement proposals to `backend/.deer-flow/improvements/<run-id>.md` after each run. The proposals are read by the next run's `before_agent` middleware and used to update the agent's behavior (system prompt patches, tool prioritization, model routing tweaks) — closing the loop at the LangGraph level.

Every layer reuses the existing primitive (`record_middleware`, `BUILTIN_TOOLS`, `RunEventStore`, `subagents/executor.py`, `scripts/serve.sh`, `sandbox/browser_circuit_breaker.py`, etc.). The 5-day plan touches ~50 files; each edit should be a wiring, not a re-implementation.

3. **Operational IDs preserved:** `deer-flow` folder, `deer-flow-dev` compose project, `deer-flow-*` containers, `deerflow.*` Python package, `DEER_FLOW_*` env vars, `backend/.deer-flow/` data dir.
4. **Non-fatal:** every new code path is wrapped so a failure can never break a run.
5. **Replay-golden must pass at every commit.** The fixture is the contract.
6. **No hallucination:** every file path cited in code, skills, or plan must exist. Per the user's explicit instruction.
7. **Coverage ≥ 80%** for new code (target layer).
8. **The 3-consecutive-completion-signals pattern:** a daily loop only signals completion if 3 sequential passes (Implement → De-Sloppify → Verify) all returned the magic phrase.
9. **The self-improving loop is opt-in by default** — `SelfImprovementMiddleware` defaults to `confidence_threshold=0.8` for auto-apply, with lower-confidence proposals only written to `.deer-flow/improvements/` for human review. This avoids runaway self-modification.

**Total estimated wall-clock:** 5 days × 5-7 hours = 25-35 hours of active `claude -p` invocation time. Per the cost guardrail ($0.50/day × 5 days = $2.50 total), the entire sprint is <$3 in API cost.
